# Code availability statement

The analysis code, operational definitions, artificial software tests and frozen aggregate figure-source data are publicly available at https://github.com/liuyi-pp/potassium-retesting (release v1.0.0). The repository does not contain patient-level MIMIC-IV records. Access to MIMIC-IV version 3.1 must be obtained independently through PhysioNet under its applicable credentialing and data-use requirements. The public package supports source inspection and aggregate figure reproduction; the full restricted-data extraction was not rerun as part of code packaging.

This is a repository-based code statement. It does not assert that every author's data-access, contribution, conflict-of-interest or AI-verification declaration has been confirmed.
